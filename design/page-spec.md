# 拾光育苗 · 逐页布局与交互说明

版本v1.0；与 `prototype.html` 的01–19页对应。画布375×812px；除特殊说明，页面左右16px，顶部内容20px，章节间24px，卡片内16px，卡片间12px。尺寸单位均为CSS px；在375px基准下转rpx乘2。系统区域和安全区按设备测量。

## 1. 页面结构与导航

```text
志愿者
我的结对 → 孩子详情 → 陪伴建议 → 新增记录 → 记录列表
                    → 成长诗阅读 → 分享卡
成长诗 → 生成成长诗 → 成长诗阅读
记录 → 新增记录 / 记录详情
我的 → 结对管理 / 信息与帮助

管理
总览 → 预警汇总 → 孩子详情 → 建议 / 跟进联系人
孩子 → 孩子详情
志愿者 → 志愿者详情 → 结对分配 / 解除结对确认
我的 → 结对分配 / 志愿者 / 预警汇总
```

顶级页面保留四项tabBar，次级页面保留左上返回。HTML左侧页面列表用于设计审阅，可自由浏览两种角色；正式产品没有这套外部导航，角色来自服务器。

## 2. 逐页设计

### 01 我的结对 · 志愿者tab

**布局**：系统导航“我的结对” → 页头品牌辅助文字10px、问候标题24px/34、说明13px → 手绘陪伴灵感卡，最小高146px，内边距20px，标题20px宋体 → 章节标题17px → 36px筛选 → 孩子卡列表 → 更新日期11px → tabBar。

孩子卡显示昵称、年级、学校、四维分数与微柱、预警标签、最近陪伴日期。每卡约174–186px，允许自然增高。手绘幼苗只出现在提示卡右侧，不干扰文字。

**交互**：点击孩子卡进入对应详情；“需跟进”筛选只显示至少一维低于60分的结对孩子；灵感卡进入小禾的建议（正式版指向当前合适对象）。下拉刷新用微信原生反馈，分页结束显示“已展示全部结对孩子”。返回恢复筛选与滚动位置，原型外部导航跳页会重置筛选。

**状态**：加载保留导航和骨架卡；空态“还没有结对的孩子”，进入结对说明；错误“暂时没能加载出来”，常驻重试。未结对不显示生成与记录对象。

### 02 孩子详情 · 两角色共用

**布局**：身份卡（64px头像、22px昵称、12px身份、预警标签） → 三列数字（24px，综合观察分/记录数/诗数） → 需要跟进时显示12px提示条 → 四维雷达卡（300×232逻辑画布） → 四列分数 → 趋势卡（310×170逻辑画布，四维切换） → AI状态解读卡 → 成长诗入口 → 陪伴时间轴。底部固定操作区。

**交互**：维度选择切换0–100同一y轴的样例曲线，节点点击显示月份与分数；不重置整页滚动。AI卡跳完整建议；诗入口打开该孩子已有诗，暂无则进入生成；时间轴打开记录详情。志愿者底部“陪伴建议 / 记一次陪伴”，管理底部“陪伴建议 / 跟进联系人”。从详情新增记录预选当前孩子。管理不能以志愿者身份提交记录。

**状态**：首次加载身份、图表、解读分区骨架；无观察显示“暂无成长观察”，不能把无观察画成四个0，记录区可独立存在；局部AI失败保留档案并局部重试；整页失败保留返回；403或关系解除提示“当前没有查看权限”并返回列表。原型状态按钮展示整页兜底状态，局部失败以本说明为实现依据。

### 03 AI陪伴建议 · 次级

**布局**：AI标识与对象周期 → 24px标题与13px解释 → 开场话术卡（16px/28px宋体、16px内边距引言、3px金色边） → 3条活动（26px编号、14px活动名、12px时间材料与说明） → 注意事项卡 → 重新生成 → 志愿者“记下这次陪伴”。

**交互**：复制开场话术，成功轻提示；浏览器权限不可用时弹层提供文本。重新生成禁用按钮，局部等待，不清空已读内容；返回详情保留阅读位置。活动不是打卡任务，不要求全部完成。

**状态**：加载局部骨架；无可用数据显示“还需要一点成长的线索”，查看档案；生成失败常驻“本次建议未能生成，原建议仍可阅读”与重试；内容审核不通过使用“这次建议暂时无法展示，请重新生成”；AI内容必须带“仅供参考，非专业诊断”和真实来源周期。实际接口若不提供来源，不伪造时间。

### 04 成长诗 · 志愿者tab

**布局**：24px“把成长，写成诗” → 44px生成按钮 → 36px孩子筛选 → 诗列表卡（128px封面、16px内边距、21px/30宋体标题、13px摘句、日期周期、AI标签）。

**交互**：点诗卡进入阅读并携带对应孩子；生成进入对象与周期选择。按结对对象过滤，不是公开发布流。列表新增诗置顶。

**状态**：加载封面和文本骨架；空态“第一首成长诗，等你写下”，生成入口；错误保持生成与导航可见并重试；某张封面失效用品牌插画替代，不让整列表失败。

### 05 成长诗阅读 · 次级

**布局**：185px乡野封面 → 24px阅读内边距 → 昵称、周期和AI标签 → 25px/38px宋体标题 → 16px/32.8px诗文，段落留一空行 → 来源说明 → 分享隐私提示。底部“再写一首 / 分享这首诗”。

**交互**：继续生成预选当前对象；分享先到预览页，不能直接公开发布。诗文过长时页面滚动，标题可多行，不截断正文。封面无需承载文字。

**状态**：诗文未生成引导生成；封面加载失败仅替换封面；诗内容不可用引导返回列表；无权限关闭访问并返回。

### 06 生成成长诗 · 次级表单

**布局**：24px标题 → 对象选择（46px） → 周期选择（46px） → 只读依据卡（对象、四维、近期足迹） → 生成说明 → 底部44px生成按钮。

**交互**：志愿者对象范围仅自己结对；管理可选择全部；周期仅列有观察的周期。切换对象和周期同步依据。提交禁用按钮，显示局部“正在拾起成长的片段”；原型1.8秒后插入示例诗，进入阅读；可返回取消演示定时器。正式版重试应带幂等控制，已产生结果不能因重复点击生成两次。

**状态**：加载对象与周期占位；无数据不能提交，说明联系管理补齐观察；接口错误保留对象与周期；超时说明“生成仍在处理中”只有后端确认有任务时才可使用，否则“暂时未能确认生成结果，请稍后查看列表”；封面失败不丢失诗文。

### 07 分享卡预览 · 次级

**布局**：17px页内标题 → 343px宽分享纸卡：154px封面、24px左右内边距、24px宋体标题、15px/28.5px诗文 → 品牌口号与印章 → 昵称显式选项 → 底部保存按钮。分享卡只放诗与品牌，不含学校、档案分数、监护人或记录照片。

**交互**：昵称默认隐藏为“给正在长大的你”；选中后展示“写给小禾”等昵称；保存当前预览内容。HTML导出750×1420px SVG，正式版Canvas按内容高度导出PNG；原型下载不申请微信权限。正式版可在相册保存后自行发送给指定人，本版不提供公开内容广场。

**状态**：卡片合成中显示局部进度；没有诗内容引导回阅读；保存失败保留预览并重试；相册拒绝提示“未保存，可前往设置允许相册权限”，不重复自动申请。长诗生成后动态增高，不能使用固定高度裁切。

### 08 陪伴记录 · 志愿者tab

**布局**：24px标题、13px说明，右侧36px视觉新增按钮（44px热区） → 孩子筛选 → 记录卡：15px标题、类型标签、13px/22px摘要、86px照片区、日期与记录人11px。

**交互**：新增进入表单；卡片进入全文；按孩子筛选；提交新记录后回列表，置顶并刷新相关时间轴。原型上传后的图片在本会话中可预览。正式列表正文建议最多3行，全文在详情展示；原型可更长以便审阅。

**状态**：骨架列表；空态“陪伴的第一页，等你写下”，新增；网络失败保留缓存与重试；搜索/筛选无结果提供清除筛选。缓存必须属于当前账户，不跨用户展示。

### 09 新增陪伴记录 · 次级表单

**布局**：对象选择 → 2×2类型按钮（探访/通话/活动/其他） → 174px最小文本域 → 计数与错误文案 → 图片3列92px高 → 可见范围说明 → 底部保存。字段间22px，控件标签间10px。

**交互**：对象预选来源孩子；文字10–1000字，图片选填0–3张；点击添加从设备选择，每张<=5MB，失败不清空其他图；删除角标；提交禁用，保存后置顶。内容不足在字段下显示错误并聚焦，不弹一个瞬时toast。原型草稿仅本次浏览器内存保存，刷新清空；正式版离开有未保存内容时提示“继续编辑 / 保留草稿后离开”，草稿范围与存储时长由工程定稿。

**状态**：对象加载；无结对对象不能提交；接口失败保留文字、类型、图片与对象；图片审核失败指出具体图片并允许移除；文本审核失败常驻说明，保留原文供修改。原型通过外部“错误”状态可验证返回重试后草稿仍在。

### 10 陪伴记录详情 · 次级

**布局**：48px昵称头像、15–17px对象与方式、12px日期记录人 → 14px/24px全文 → 图片 → 观察说明条。

**交互**：点图片预览；原型真实上传图片用弹层，初始示例插画用说明弹层；正式用wx.previewImage。返回到原列表或孩子时间轴。此版没有编辑/删除记录接口，不增加隐含操作。

**状态**：分区骨架；记录撤回/删除显示“这条记录暂时不可用”；失败重试；无权限返回上级，不泄露记录正文。

### 11 我的 · 志愿者tab

**布局**：64px头像、22px昵称、组织与角色 → 3列统计 → 菜单组（志愿者信息、结对管理、我的记录） → 隐私/帮助/关于 → 品牌口号。菜单最小58px，行图标20px。

**交互**：结对管理和记录跳页；个人资料、帮助与隐私原型展示说明弹层，未假装存在保存接口。账号角色不可以在此升权。

**状态**：资料加载保留菜单；无资料提示完善信息的说明；登录过期引导重新登录；退出正式需清除token与当前账户敏感缓存。

### 12 结对管理 · 志愿者次级

**布局**：24px标题、结对数说明 → 金色说明条 → 已结对孩子卡。

**交互**：查看档案；调整结对由管理处理，本页不显示分配、解除或其他志愿者联系方式。正式“联系组织”只有在有实际渠道时才设置可执行按钮。

**状态**：加载关系骨架；空态联系管理；失败重试；关系更新刷新对象范围。

### 13 总览 · 管理tab

**布局**：24px标题与计划周期 → 2×2指标卡（孩子数、志愿者数、平均观察分、需跟进人数），每卡165.5px宽、16px内边距、30px数字 → 预警汇总 → 综合等级横条图 → 未结对入口。

**交互**：预警“全部”进入汇总，预警行进入对应档案；未结对入口进入分配。总览5个孩子、3位志愿者、平均72分、需跟进2人；分布优秀2/关注2/预警1/高危0。数据周期相同，管理不要把孩子分数作为志愿者绩效榜。

**状态**：指标与列表骨架；无数据引导在后台建立档案；部分指标失败保留其他指标并“—”占位；全页失败常驻重试。0人时平均分显示“—”不是0，分布不计算除以零。

### 14 预警汇总 · 管理次级

**布局**：24px说明标题 → 全部/高危信号/预警信号筛选 → 卡片列：孩子、学校、周期、严重程度；每个异常维度独立12px摘要；结对人；查看档案按钮。

**交互**：按最严重单维信号筛选孩子，汇总按孩子去重；详情仍列每个异常维度；进入档案查看上下文与建议。联系先定位结对人，不自动发送消息。

**状态**：加载卡片；无预警“当前没有需要跟进的预警”可查看全部孩子；失败重试。界面不可把过期预警显示成已处理，当前无处置接口，因此不设计伪“处理完成”按钮。

### 15 孩子 · 管理tab

**布局**：44px搜索 → 36px全部/需跟进/未结对筛选 → 统一孩子卡，底栏增加结对志愿者或“尚未结对”。

**交互**：搜索昵称、学校、年级或结对人；对象进入详情并保持管理角色；未结对名单与分配页一致。原型本地包含检索，正式服务端分页时需明确排序、查询与防抖；建议输入结束300ms后请求。

**状态**：加载骨架；未建档引导后台；筛选零结果提供清除筛选；请求失败保留现有列表与输入，避免数据闪空。

### 16 志愿者 · 管理tab

**布局**：44px搜索 → 17px章节与分配按钮 → 48px头像、17px姓名、组织、结对数的卡片。

**交互**：检索姓名/组织，进入志愿者详情；分配入口进入确认流程。状态仅展示在岗，不凭原型添加禁用账户功能。

**状态**：列表骨架；无人加入说明登录加入服务计划；零结果清除搜索；错误保留搜索条件与重试。

### 17 志愿者详情 · 管理次级

**布局**：64px头像、22px姓名、组织与在岗标签 → 结对数、数据范围信息行 → 结对列表 → “新增结对” → 调整权限说明。

**交互**：档案入口；新增结对预选该志愿者；解除先确认“将解除某人与某孩子结对，访问权限将失效”，确认才模拟修改关系；取消不改变数据。正式DELETE用relation id，不按昵称定位。实际成功后更新详情、总览未结对数、孩子卡与志愿者数据范围。

**状态**：加载骨架；无结对引导分配；解除失败保留关系，常驻错误与重试；关系已被其他管理变更提示刷新，不默默覆盖。

### 18 结对分配 · 管理次级

**布局**：24px标题 → 46px志愿者选择 → 待分配孩子选择列表（18px单选、58px以上热区） → 分配摘要 → 规则提示 → 底部确认。

**交互**：原型一次选择一位孩子与一位志愿者；点击确认弹层核对；确认后只更新本次演示内存，进入志愿者详情。原型默认每孩一名主陪伴者，后端未锁此数量规则；多对多正式模式需调整列表与重复关系校验，不能据原型擅自锁唯一性。角色权限仍由服务端校验。

**状态**：对象骨架；全部已结对可返回志愿者列表；未选择孩子在字段下报错；提交失败保留选择；重复关系/并发变化提示刷新对象，不能对同一点击创建重复关系。

### 19 我的 · 管理tab

**布局**：管理身份卡、组织、可见范围与职责 → 分配/成员/预警入口 → 隐私帮助关于 → 退出登录。

**交互**：管理快捷入口；退出说明与正式清理行为；无前端角色切换。组织信息固定为服务端授权范围。

**状态**：身份加载；缺组织资料联系负责人；资料失败重试；登录过期重新登录，确认role后回到正确tab。

## 3. 状态矩阵与验收方式

原型右上外部按钮在每个页面可切换“正常 / 加载 / 空态 / 错误”，共19×4=76个可审阅页面状态。页面级骨架和错误共用组件，但空态文案与下一步按页面区分。正式实现应根据模块细分，不因封面或AI局部失败遮住已加载的档案。

| 类型 | 显示范围 | 信息 | 用户下一步 | 数据保持 |
|---|---|---|---|---|
| 首次加载 | 对应列表/卡片 | 骨架、不同时多动画 | 等待或返回 | 导航保留 |
| 下拉刷新 | 页面顶部原生 | 原生加载反馈 | 可继续浏览 | 现有数据不清空 |
| 空列表 | 内容区 | 原因与引导 | 分配/生成/新增/帮助 | 不制造假数据 |
| 筛选无结果 | 列表区 | 未匹配当前条件 | 清除筛选 | 输入与筛选保留 |
| 断网 | 失败模块 | 原因常驻 | 重试或返回 | 缓存与草稿保留 |
| 表单校验 | 字段旁 | 具体错误 | 修改后重试 | 其他字段保留 |
| AI等待 | 生成局部 | 明确等待文案 | 返回或等待 | 已有内容不清空 |
| 审核未通过 | 内容模块 | 暂无法展示/请修改 | 修改或重新生成 | 安全的已提交数据保留 |
| 无权限 | 页面内容区 | 访问范围已变更 | 返回列表 | 清除该对象敏感缓存 |
| 保存成功 | toast + 新内容 | 操作完成 | 阅读结果 | 列表/时间轴同步更新 |
| 相册拒绝 | 预览页 | 未保存及授权方法 | 设置或返回 | 分享预览保留 |
| 并发结对冲突 | 表单与确认区 | 对象关系已变更 | 刷新再确认 | 不自动覆盖现有关系 |

## 4. 微文案原则

用“陪伴、观察、尝试、表达、跟进”描述行为；用具体记录说明变化，不称孩子为“问题儿童”“高危儿童”。后台等级名称可以在管理统计中使用，个体卡片优先使用行动型提示。AI状态、诗文与图片按实际生成情况标记，不把示例数据说成真实运营数据。

说明应短而可行动，例如“请至少写下10个字的陪伴观察”“暂时没能加载出来，请检查连接后重试”“未保存，可前往设置允许相册权限”。错误不能只写“操作失败”而无下一步。

## 5. 建议演示顺序

1. 志愿者我的结对 → 小禾档案 → 切换心理趋势 → 读取开场话术 → 新增图文记录 → 返回足迹。
2. 成长诗 → 选择孩子与周期 → 等待示例生成 → 阅读 → 匿名分享预览 → 保存SVG。
3. 管理总览 → 小川预警 → 档案（高危单维与综合预警差异） → 返回成员 → 分配小雨 → 二次确认。
4. 任选页面展示加载、空态、错误并重试；演示新增记录失败后输入保留。

用于说明评审中的体验与技术实现路径，不宣称已完成真实上线或运营。运营证据应由团队在真实小程序阶段补齐。
